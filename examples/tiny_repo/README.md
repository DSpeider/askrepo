# Tiny billing sample

Small tree used by the askrepo quickstart, tests, and retrieval eval.

`calculate_invoice_total` lives in `src/billing/invoice.py` and calls `apply_tax`.
Checkout, catalog, shipping, and receipt modules sit beside that pair.

`node_modules/`, `build/`, and `.env` are present so indexing can show they are skipped. `docs/overview.md` mentions invoices in prose and does not define the function.
